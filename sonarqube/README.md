# SonarQube

This directory contains the configuration required to deploy SonarQube
for static code analysis and code quality checks.

## Purpose

SonarQube is used in this project to:

- Analyze application source code
- Detect bugs
- Detect code smells
- Identify security vulnerabilities
- Measure code coverage
- Enforce quality gates
